- [ ] **🔴 ACTION CRITIQUE — Passer le compte en professionnel :**
  - Aller dans Paramètres → Type de compte → Passer en compte professionnel
  - **Choisir "Créateur" (Creator)** — pas "Business / Entreprise"
  - ⚠️ Creator est le type qui permet le product tagging dans les Reels organiques

### Pourquoi Creator plutôt que Business ?

Le schéma pour taguer des produits dans un Reel organique est :

```
Compte Creator → marque avec catalogue Meta → autorisation product tagging
→ Reel organique → tag produit → clic vers fiche produit / site de la marque
```

En mode Creator :
- Tu peux taguer des produits dans tes Reels organiques (pas besoin de pub payante)
- Tu peux utiliser le label "Partenariat rémunéré avec..." si tu es rémunéré
- Tu peux mettre des liens affiliés dans tes posts/Reels

En mode Business :
- Plus restreint pour le product tagging organique
- Conçu pour les marques, pas pour les créateurs

- [ ] ✅ Vérifier que "Compte Créateur" est bien affiché dans les paramètres

## Annexe B — Schéma de tagging produit (à savoir pour la suite)

Une fois les comptes créés, pour taguer des produits dans un Reel organique, il faut :

| Condition | Détail |
|-----------|--------|
| 1. Compte Instagram | Professionnel **Creator** — c'est fait ✅ |
| 2. Compte en règle | Pas de restrictions en cours |
| 3. Produit disponible | La marque doit avoir une boutique Instagram / catalogue Meta |
| 4. Autorisation marque | La marque donne la permission de product tagging dans ses réglages |
| 5. Partenariat déclaré | Si rémunéré → label "Partenariat rémunéré avec..." |
| 6. Produit conforme | Doit respecter les règles commerce Meta, lien vers domaine valide |

**Le flux final :**
```
Compte Creator → marque avec catalogue Meta → autorisation product tagging
→ tu crées un Reel organique → tu tagues le produit dans le Reel
→ les gens cliquent → fiche produit / site de la marque
```
