# Agents actifs — Le Lab

## Rôle du fichier

`AGENTS-ACTIFS.md` recense les agents permanents du Lab.

Il permet à Alan de savoir rapidement quels agents existent, quel est leur rôle, où se trouve leur fichier Markdown, leur statut actuel, leur dernière mission et leur dernière mise à jour.

Les agents temporaires ne sont pas listés ici, sauf exception décidée par Alan.

## Règles générales

- Alan est responsable de la cohérence globale des agents.
- Chaque agent permanent possède son propre fichier Markdown.
- Les agents sont activés au fil de l’eau selon les besoins.
- Chaque agent peut mettre à jour son propre fichier Markdown.
- Les fichiers centraux sont validés par Alan.
- Alan peut créer des agents temporaires pour une mission précise.
- Les agents temporaires sont supprimés après mission.
- Alan peut renommer, déplacer, fusionner ou supprimer un agent si cela améliore le projet.
- Aucune information utile ne doit être perdue.
