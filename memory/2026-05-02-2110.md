## Décisions prises

### Architecture comptes
- 26 portfolios (A → Z), 1 prénom par portfolio
- 10 comptes publication + 1 compte admin par portfolio (strateur)
- 3 réseaux par identité : Facebook (page), Instagram, TikTok (optionnel)
- MDP réseau : `Prénom1!` (ex: `Adam1!`)
- MDP admin : `Prénom.admin1!`
- Date naissance unique : 1990-01-01
- Suffixes email : `.reel`, `.story`, `.content`, `.media`, `.feed`, `.post`, `.daily`, `.vibe`, `.style`, `.life`
- Admin suffixe : `.strateur`
- BDD : 1 ligne par réseau avec `id_identite` pour grouper
- Pas de YouTube (écosystème Google trop compliqué)
- Compte admin = pas d'Instagram, pas de TikTok
